# 3D-Viewer / CAD-Workflow

This skill lives inside the project: `<project>/.devin/skills/3d-viewer`.
Paths below are relative to the project root (`3d-viewer/`).
User selects elements in the browser viewer; IDs (P/E/F) refer to the
viewer topology, NOT to model.py parameters — always resolve them first.

## Files

- `model.py` — parametric model source (trimesh + manifold3d). Edit params, run `python model.py`.
- `model.stl` — generated binary STL (mm), regenerated by model.py.
- `index.html` — Three.js viewer (selection, auto-copy of IDs to clipboard).
- `serve.py` — local server on :8000, `start.bat` launches it.
- The viewer auto-reloads ~3s after model.stl changes and keeps the camera.

## Resolving selection IDs (P<n>, E<n>, F<n>)

Run the bundled script from the project root:

    python .devin\skills\3d-viewer\chain_report.py [ids...]

It prints every edge chain (id, length, closed, endpoint coords) and,
with args like `14 17`, details for those chains. Chain/face/vertex IDs
match the viewer exactly (same weld tolerance, same smooth-union angle
0.94, same 30° chain-merge threshold — keep them in sync if viewer logic
changes).

Selection text in clipboard looks like:
    Modell: <name>
    Punkte: P12, P34
    Kanten: E5
    Flächen: F0, F3

## Common model.py operations

Current model in `model.py`: open-top case (cadquery). `examples/dragon.py` holds
an organic model (implicit SDF modeling) — same output `model.stl`.

- Overall size: `L, W, H`
- Fillets: `R_VERT`, `R_BOT` (outer), `R_INNER_*` are DERIVED
  (outer radius - WALL) for uniform wall thickness.
- Screw bosses in inner corners: `BOSS_*` — placed on the 45° diagonal
  inside the inner corner arc so they fuse but never pierce the skin.
- Vent slots: `VENT_*` (capsule profile via slot2D, tilt via VENT_ANGLE).

## Organic shapes: implicit SDF modeling (examples/dragon.py)

For organic parts, don't fight B-rep/CSG — build a signed-distance field
on a voxel grid and run marching_cubes (skimage). Always watertight.

Building blocks (verified signatures — DO NOT change signs blindly,
getting them wrong destroyed the whole model once):

- `smin(a, b, k)` — smooth union: `h=clip(0.5+0.5*(b-a)/k)`;
  `b*(1-h)+a*h - k*h*(1-h)`
- `sdiff(a, b, k)` — smooth subtraction of shape b:
  `-smin(-a, b, k)` (equivalent to max(a, -b) with rounding)
- Primitives: `ellipsoid`, `sphere`, `capsule_chain(pts, rads)`
  (tapered tube along polyline — horns), `cone(base, tip, r)` (teeth)

Pitfalls learned the hard way:

- Floating parts: a cone/sphere whose base sits inside a cavity or
  cut region floats in mid-air. Anchor every additive part so its base
  is INSIDE solid material (extend it past the surface it grows from).
- A subtract that spans a whole section (e.g. a mouth slit through the
  entire snout) severs the model into pieces — keep cuts shallow or
  check connectivity after.
- Hard `np.maximum` cuts leave voxel-fuzz edges; use `sdiff` with
  small k (1-2.5) for rounded cut edges.
- When the result looks wrong, don't guess: run
  `python preview.py model.stl <elev> <azim>` to self-render a PNG,
  or split the mesh into bodies (`m.split()`) to find detached parts.
- Field debug: print `(field < 0).sum()` after each stage — a sudden
  drop to ~0 means a subtraction is inverted.

Deps: `pip install --user scikit-image fast-simplification shapely`
(--user is mandatory, C:\Python311 is not writable).

## Finish checklist (always)

After ANY model change:

1. `python model.py` (or `examples/dragon.py`) in `3d-viewer` — check output
   is watertight. For organic models, ALSO run `python preview.py`
   and look at the PNG before telling the user it's done.
2. Tell the user the STL regenerated; the viewer auto-reloads within
   ~3 s and keeps the camera. Never skip this step — a change without
   the regenerated STL is invisible.
3. If IDs were referenced, note that chain IDs may shift; suggest the
   user re-selects elements for further edits.
